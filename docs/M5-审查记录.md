## 保留限制与后续门禁

真实模型仍返回 402；当前只能报告 Agent dev 的基础设施失败、冻结 test 未运行和成本未知。供应商恢复后需要保留全新 dev/test 尝试和用量，才能完成最终对比与真实演示。不能用规则基线、固定模型测试或旧 M0/M2 的成功调用替代它。
