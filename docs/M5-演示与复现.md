# M5 演示与复现

本文件适用于 Windows PowerShell。常规服务启动和新机器配置见根目录 README；不要覆盖已填写的 `.env`。Python、uv、Node、Docker Desktop Linux Engine 和 Edge 是已验证环境，依赖版本以两个锁文件为准。

## 源码克隆：先生成报告，再复算（无模型请求）

先按 README 完成克隆、依赖安装、本地配置和 PostgreSQL 启动。在项目根目录执行；源码仓库没有历史 `artifacts/`，下面会创建新报告，输出文件必须尚不存在。

```powershell
$env:M0_TEST_ADMIN_URL = 'postgresql://ticketpilot:local-dev-only@127.0.0.1:5432/postgres'
$report = '../artifacts/fixed-' + [guid]::NewGuid().ToString('N') + '.json'
$rescored = $report.Replace('.json', '-rescored.json')
uv run --directory backend --locked python -m evaluation.run --baseline fixed --split all --output $report
if ($LASTEXITCODE -ne 0) { throw '固定流程未完成，请检查本次报告。' }
uv run --directory backend --locked python -m evaluation.rescore --input $report --output $rescored
```

重算只读取 JSON、冻结案例和评分代码，不访问网络或数据库。案例 hash 不一致时拒绝换标签；输出路径已存在时拒绝覆盖。原始请求用量、耗时和源码 hash 保留，评分代码 hash 另记。不同机器重新执行端到端运行的耗时会波动；重算已存测量的分子、分母和分位数应一致。

当前评分版本 m5-v3。新固定流程预期 dev 4/4、test 12/12；CI 会核对新报告与复算摘要一致。旧报告没有全库副作用快照时，重算会标记 revalidation_required，并把无法证实的安全率设为 null；这不等于重新执行了测试。历史文件仅见本地交付包，详见 [修复验证](M5-修复验证.md)。

## 重新运行固定流程

下面连接仅指向本机 Docker PostgreSQL 的公开合成测试账户；测试需要 CREATE DATABASE 权限。运行器只创建和删除自己的随机库，不清空 ticketpilot 演示库。

```powershell
$env:M0_TEST_ADMIN_URL = 'postgresql://ticketpilot:local-dev-only@127.0.0.1:5432/postgres'
uv run --directory backend --locked pytest -q
uv run --directory backend --locked ruff check app migrations tests simulator evaluation
uv run --directory backend --locked ruff format --check app migrations tests simulator evaluation
```

前端命令在 frontend 中执行。当前宿主机的 npm 包装器会把 `npm run ... -- --reporter` 当成自身参数，因此直接使用锁定的 Playwright CLI：

```powershell
cd frontend
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
node node_modules/@playwright/test/cli.js test
cd ..
```


[GitHub Release 演示入口](https://github.com/ddy-007/TicketPilot/releases/tag/demo-2026-10-23) · [直接下载 MP4](https://github.com/ddy-007/TicketPilot/releases/download/demo-2026-10-23/TicketPilot-demo-2026-10-23.mp4)。仓库和视频保持私有，观看者需要仓库权限；该视频记录此前版本的固定模型演示，不是本轮真实 dev 成功证据。

最终 MP4（本地：`artifacts/m5-demo-delivery-2026-10-23.mp4`） 为实际浏览器操作录制，1440×900、H.264、180 秒，带中文字幕、无旁白。字幕是录制脚本附加的说明层，不是产品功能。前 150 秒保留实际批准、拒绝和版本冲突流程，最后 30 秒为根据测量报告制作的结果卡；原录屏另行保留。PostgreSQL、HTTP 模拟器、API、审批、Worker 和业务效果均实际执行；只有模型使用固定替身，全程标注。

| 时间 | 内容 | 核对点 |
|---|---|---|
| 00:00–00:30 | 问题、范围与工单 | 合成业务、单场景、模型只有只读工具 |
| 00:30–01:00 | 查证、证据、审批提案 | 操作员不能批准；提案尚未执行 |

| 01:15–01:40 | 正式批准、受控执行 | Run=1、RESUME Job=1、业务效果=1；仅重新入队 |
| 01:40–02:00 | 人工拒绝 | 业务效果=0 |

录制脚本拒绝覆盖现有 MP4，拒绝复用占用的 8023 端口，始终启动随机独立库；结束后请求夹具优雅关闭以执行 finally 清理。录像不登录原 8010 工作台，不读取本地角色 Token。

```powershell
# Edge 已安装；Playwright 录像还需要自己的小型 FFmpeg 组件。
cd frontend
```

Linux 可设置 `PLAYWRIGHT_CHANNEL=chromium`，先安装锁定 Playwright 对应的 Chromium、FFmpeg 和中文字体，再执行同样的浏览器与录像命令；Windows 默认仍使用 Edge。仓库的 `Independent machine reproduction` 手动工作流在全新 GitHub Ubuntu VM 执行源码配置初始化、Docker 空库启动/seed、跨容器恢复、新报告及复算、25 项浏览器全流程和三分钟录像，不注入模型密钥。异机演示仍明确使用固定模型，真实模型 dev/test 单独验收。

## 本地交付包：复核历史证据

本节只适用于拿到附带 `artifacts/` 和 `DELIVERY-MANIFEST.json` 的本地 ZIP；GitHub 源码克隆应使用开头的新报告流程。解压到新目录，先按清单核对文件 SHA-256，再安装依赖；包内没有 `.env`，需要自行初始化。

例如该历史包确实包含下列文件时，可离线复算（不调用模型或数据库）：

```powershell
uv run --directory backend --locked python -m evaluation.rescore --input ../artifacts/m5-fixed-v3-2026-10-23.json --output ../artifacts/historical-fixed-rescored.json
uv run --directory backend --locked python -m evaluation.rescore --input ../artifacts/m5-agent-dev-2026-10-20.json --output ../artifacts/historical-agent-rescored.json
```

最新全项目修复包为 `artifacts/TicketPilot-project-fixes-2026-10-23.zip`，修复验证见 [全项目修复说明](全项目审查-修复验证.md)。此前 `TicketPilot-M5-repaired-2026-10-23.zip` 和 `TicketPilot-M5-delivery-2026-10-23.zip` 作为历史版本保留。新包包含当前源码、两个依赖锁文件、文档及选择的前后证据，不含 `.env`、已安装依赖、数据库文件或生产数据。`DELIVERY-MANIFEST.json` 记录每个文件 SHA-256 与未完成状态；不能把交付包的存在当作真实模型最终验收通过。

打包脚本要求本地历史证据齐全，仅交付维护者使用；不属于 GitHub 克隆复现步骤。重新打包可指定新路径：

```powershell
uv run --directory backend --locked python ../scripts/package_m5.py --output ../artifacts/TicketPilot-M5-delivery-copy.zip
```
