# 克隆复现、CI 与执行计时完善

日期：2026-10-23。

## 本轮变更

- README 和复现文档分别说明源码克隆与本地交付包：源码先生成新固定流程报告，再复算同一文件，不再要求历史 JSON；随机输出路径避免覆盖旧尝试。
- `scripts/init_local_env.py` 在 `.env` 不存在时根据模板创建配置，生成四枚随机 Token；已有文件既不读取也不改写，模型配置保持空值。Docker 普通启动与真实模型 Worker 启动分开说明。
- GitHub Actions 在 push/PR 执行 Ruff、暂存源码隐私检查、Python 3.11/3.12 完整后端测试、隔离 PostgreSQL、前端类型检查/单测/构建，以及新报告生成和复算。测试结果检查要求 0 skipped。Actions 固定到完整 commit SHA，权限为 contents:read，checkout 不持久化凭证。
- 真实模型工作流仅手动触发，限定 main、显式付费确认和 1～72 次总调用预算，默认 1；模型 Secrets 只注入评测步骤。未向 GitHub 上传本地 `.env` 或密钥，也未触发云端付费模型工作流。调用次数上限并非金额上限。
- BusinessClient 每次 HTTP 尝试记录 UTC `started_at`、`observed_at`、单调时钟 `duration_ms` 和实际 `backoff_ms`。耗时在响应流关闭后、退避之前冻结；审批检查耗时不混入 HTTP，审批未通过时 started_at=null、duration_ms=0。GET 的状态码重试/网络重试规则和 POST 不重试规则保持原样。
- 新增回归覆盖两次 503 后成功、网络异常后成功和 POST 失败：每次 HTTP 25 ms，503 退避分别 100/200 ms；POST 的 700 ms 授权检查排除在请求耗时之外。原审批失败测试同时检查没有 HTTP 开始时间或等待。
