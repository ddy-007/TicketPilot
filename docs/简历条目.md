# TicketPilot 简历条目

截至 2026-10-23 可使用：

> **TicketPilot：可审批、可恢复的售后履约重试 Agent**  
> 基于 FastAPI、LangGraph 与 PostgreSQL 实现单场景工单查证、只读工具调用、结构化提案、人工审批和受控履约重试；结合持久任务、检查点、稳定业务幂等键及订单版本校验，支持审批中断恢复、写响应丢失后的结果查证和重复执行防护。构建 16 条分层合成评测案例，固定流程基线 dev 4/4、test 12/12 符合预期；后端完整回归 253 项通过，浏览器验收 25 项通过。真实模型 M5 评测因供应商 HTTP 402 尚未完成，不报告模型成功率或成本收益。

短版：

> 基于 FastAPI、LangGraph 与 PostgreSQL 实现可审批、可恢复的履约重试 Agent；通过 checkpoint、持久队列、业务幂等及版本校验验证中断恢复与单键至多一次业务效果，完成 16 条合成规则基线评测和 25 项浏览器验收。

面试时区分：规则基线结果、固定模型的软件测试、真实供应商模型评测。当前没有充分证据填写“Agent 成功率 100%”“模型提高效率 X%”“成本降低 X%”或“生产级双人审批”。未观测到违规只描述实际覆盖样本，不代表绝对安全。

工程验证可补充：配置 GitHub Actions，在 Python 3.11/3.12 和隔离 PostgreSQL 上自动运行完整后端回归，并执行 Ruff、前端类型检查与构建、新报告生成及离线复算；首轮云端全部通过。演示入口为[私有 Release 三分钟视频](https://github.com/ddy-007/TicketPilot/releases/tag/demo-2026-10-23)，需提前给观看者仓库权限，固定模型演示不作为真实模型验收。
