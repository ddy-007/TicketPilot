# TicketPilot 简历条目

截至 2026-10-23 可使用：

> **TicketPilot：可审批、可恢复的售后履约重试 Agent**  
> 基于 FastAPI、LangGraph 与 PostgreSQL 实现单场景工单查证、只读工具调用、结构化提案、人工审批和受控履约重试；结合持久任务、检查点、稳定业务幂等键及订单版本校验，支持审批中断恢复、写响应丢失后的结果查证和重复执行防护。构建 16 条分层合成评测案例，固定流程 16/16、真实模型 dev 3/4及首次冻结 test 12/12 符合预期；58 次真实调用完整记录 usage，按公开价估算约 ¥0.089。通过 Python 3.11/3.12 各 267 项后端回归，以及独立 Ubuntu 虚拟机的 Docker 部署、25 项浏览器验收与三分钟演示。

短版：

> 基于 FastAPI、LangGraph 与 PostgreSQL 实现可审批、可恢复的履约重试 Agent；以 checkpoint、持久队列、幂等及版本校验验证中断恢复和重复执行防护。完成真实模型 dev 3/4、冻结 test 12/12 的合成场景评测，以及独立云端机器的 25 项浏览器验收。

面试时区分：规则基线结果、固定模型的软件测试、真实供应商模型评测。真实模型合计 15/16，dev 唯一失败为付款仅十分钟时诊断码冲突，已被规则转人工并拦截写入，不能删去。test 12/12 只描述这次小样本首测；本场景固定流程更快，不能声称“模型提高效率”“成本降低”或生产成功率 100%。未观测到违规只描述实际覆盖样本，不代表绝对安全。

工程验证可补充：配置 GitHub Actions，在 Python 3.11/3.12 和隔离 PostgreSQL 上自动运行完整后端回归，并执行 Ruff、前端类型检查与构建、新报告生成及离线复算。演示入口为[最终私有 Release](https://github.com/ddy-007/TicketPilot/releases/tag/m5-final-2026-10-23)，需提前给观看者仓库权限；录像使用固定模型，真实评测报告与证据包另列。
