## 仓库中的隐私边界

- 本仓库使用合成业务数据。本地 `.env`、凭证文件、数据库、运行日志、浏览器截图/录像、源码交付压缩包、已安装依赖和 IDE 配置不提交。
- `artifacts/` 是仅保留在本地的原始证据目录；历史文档中的该目录路径用于本地复核，不表示 GitHub 已托管原始文件。本页提供适合随源码共享的结果摘要。
- `local-dev-only` 数据库密码、重复字母测试 Token 和文档占位符是公开的本地测试数据，不得复用于真实系统或公开部署。
- Git 提交使用 GitHub noreply 邮箱；不把个人邮箱或设备用户名写入提交身份。
- 推送前对实际暂存的文件内容运行 `python scripts/check_privacy.py`，检查常见凭证格式、个人设备路径、邮箱、手机号和禁止上传的文件类型；脚本不读取被忽略的配置，也不输出匹配内容。
- 静态匹配不能保证发现所有秘密。后续添加文件时仍需检查 `git diff --cached`，尤其不能强制添加本地凭证或完整运行日志。

## 复核命令

按 README 配置独立测试 PostgreSQL 后，可重新运行后端、前端、浏览器和固定基线。真实模型评测必须另外显式使用 `--real-model`，并设置预算；普通软件回归不会调用真实模型。
